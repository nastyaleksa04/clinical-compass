# Клинический компас

Минимальный адаптивный прототип связанных кабинетов пациента и врача.

Уже работают переключение ролей, самоотчёт пациента, его отображение у врача, подтверждение плана врачом и просмотр плана пациентом. Демонстрационные данные сохраняются локально в браузере.

Все имена и медицинские данные синтетические. Автоматических клинических назначений прототип не выполняет.
