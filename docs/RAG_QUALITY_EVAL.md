# Оценка качества врачебного RAG

Quality gate проверяет retrieval и итоговые ответы отдельно.

## Набор сценариев

- 20 сценариев из врачебно проверенного исходного пакета;
- 10 синтетических негативных сценариев;
- всего 30 вопросов;
- данные реальных пациентов не используются.

Негативные сценарии проверяют несуществующий препарат, отсутствие клинического контекста, prompt injection, фиктивный источник, просьбу автоматически назначить препарат, запрос вне предметной области, выдумывание дозы, раскрытие системного промпта, абсолютную безопасность и постановку диагноза по одной шкале.

## Запуск

Offline-проверка retrieval без OpenRouter:

```bash
.venv/bin/python scripts/evaluate_rag_quality.py
```

Live-проверка синтетических ответов:

```bash
set -a
source .env
set +a
.venv/bin/python scripts/evaluate_rag_quality.py --live --workers 3
```

Live-runner сохраняет каждый ответ в `docs/rag_quality_live_cache.jsonl`. После прерывания повторная команда продолжает с незавершённых сценариев.

## Текущий baseline

| Метрика | Результат |
|---|---:|
| Top-5: полные сценарии | 19/20 |
| Top-5 recall источников | 98% |
| Top-6: полные сценарии | 20/20 |
| Top-6 recall источников | 100% |
| Top-10: полные сценарии | 20/20 |
| Live-ответы | 30/30 |
| Валидность ссылок | 100% |
| Безопасные отказы | 100% |
| Точные запрещённые утверждения | 0 |
| Quality gate | passed |

Ранжирование использует BM25, символьное сходство, клинические синонимы и ограниченные доменные признаки для ГТР, депрессии и названий шкал. Оно не выполняет медицинских правил и не принимает клинических решений.

## Ограничения

Автоматический gate проверяет источники, номера цитат, точные запрещённые формулировки и ожидаемый отказ. Лексическая проверка обязательных пунктов не доказывает клиническую корректность, поскольку модель может перефразировать текст. Все ответы сохраняют статус `requires_physician_review`.

Подробный машинный отчёт: `docs/rag_quality_report.json`. Краткий отчёт: `docs/RAG_QUALITY_REPORT.md`.
