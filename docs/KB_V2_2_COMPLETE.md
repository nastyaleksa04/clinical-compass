# Полная врачебная база знаний KB v2.2

KB v2.2 сохраняет все содержательные записи исходного врачебного пакета и предназначена для локального RAG-поиска в кабинете врача.

## Состав

- 28 источников;
- 81 клиническое состояние или рекомендация;
- 60 записей о препаратах;
- 25 карточек препаратов;
- 72 правила безопасности и маршрутизации;
- 32 строки шкал;
- 20 eval-сценариев;
- 28 полей модели пациента;
- 247 поисковых чанков.

Файлы находятся в data/knowledge/kb_v2_2_complete_doctor/, готовый архив — data/knowledge/kb_v2_2_complete_doctor.zip.

## Границы применения

Все 247 чанков доступны только роли врача. База не выдаётся пациенту и не используется для автоматического назначения или изменения лечения.

Полнота поиска и разрешение автоматизации разделены. В поиск включены все записи, но 42 записи имеют запрет на автоматическое исполнение:

- 18 записей препаратов без подтверждённой инструкции;
- 24 правила, триггеры которых требуют ручной формализации.

Исключения перечислены в quarantine/automation_exclusions.jsonl. Система сохраняет их в RAG для справочного поиска, но не может выполнить как правило.

## Воспроизводимая сборка

~~~bash
python3 scripts/build_complete_kb.py --zip
python3 scripts/audit_kb.py data/knowledge/kb_v2_2_complete_doctor \
  --json-output docs/kb_v2_2_audit.json \
  --markdown-output docs/KB_V2_2_AUDIT.md
python3 scripts/evaluate_retrieval.py
~~~

Eval набора v2.2 при Top-10: 20 из 20 сценариев полностью пройдены, найдено 50 из 50 ожидаемых ссылок, micro recall 100%.

Это оценка нахождения подготовленных источников. Она не доказывает клиническую правильность будущего ответа LLM. Ответы помощника должны содержать цитаты, а клиническое решение остаётся за врачом.
