# Локальный retrieval для врача

Версия: 0.14.0. Индекс: kb_v2.2-complete-doctor.

## API

POST /api/rag/search доступен только роли doctor.

~~~json
{
  "query": "пароксетин доза при ГТР",
  "limit": 5
}
~~~

Результат содержит позицию и оценку релевантности, текст чанка, ID сущностей, источник, URL, страницу или раздел evidence и релиз индекса.

Поиск полностью локальный и пока не вызывает LLM или внешние API. Ранжирование объединяет BM25-подобную оценку, нормализацию русских окончаний, символьные триграммы, усиление точных сущностей и лексическое переранжирование явных сигналов риска. Переранжирование не исполняет медицинские правила и не устанавливает диагноз.
