# AI-сводка клинического случая

В версии 0.17.0 врач может сформировать черновик сводки прямо в карточке пациента.

## Что попадает в сводку

- возраст без имени и контактов;
- врачебный клинический профиль;
- последние результаты PHQ-9/GAD-7;
- самоотчёты и динамика;
- приверженность и нежелательные реакции;
- сигналы маршрутизации;
- решения по терапии и задачи наблюдения.

ФИО, телефон, email, экстренный контакт и переписка не передаются в OpenRouter. Телефоны, email, имя пациента и длинные идентификаторы дополнительно удаляются из свободного текста.

## Как работает

Endpoint `POST /api/patients/{patient_id}/ai-summary` доступен только врачу. Сервер обезличивает данные, подбирает до 6 фрагментов врачебной KB v2.2 и передаёт их Qwen через OpenRouter. Ответ содержит черновик, цитаты, статус проверки ссылок и сведения о версии корпуса.

Сводка не сохраняется в медицинскую карту и не меняет план, маршрутизацию или терапию. Врач проверяет её вручную.

## Проверка

```bash
python -m unittest tests.test_clinical_summary -v
```


## Проверка и сохранение

После генерации врач может открыть редактирование, изменить текст и нажать «Подтвердить и сохранить». До подтверждения черновик не записывается в карту. После подтверждения локально сохраняются исходный AI-текст, итоговая редакция врача, модель, версия базы, цитаты, имя подтверждающего врача и время. Запись видна только врачу и появляется в истории наблюдения.
