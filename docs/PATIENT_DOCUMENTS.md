# Документы пациента

Версия прототипа: 0.23.0.

В кабинете пациента раздел «Моя медкарта» → «Документы» формирует два психиатрических PDF по актуальной карточке конкретного пациента:

- отчёт психиатрического приёма: жалобы, анамнез, рабочая гипотеза врача, клинически значимые признаки, последние шкалы, подтверждённый план и подтверждённые решения по терапии;
- результаты опросников и динамика: история PHQ-9/GAD-7, самоотчёты, приверженность и задачи наблюдения.

PDF не загружаются и не хранятся в проекте. `app/documents.py` собирает документ в памяти при каждом открытии, поэтому он отражает текущее состояние SQLite-карты. Маршруты `/api/patients/{patient_id}/documents` и `/api/patients/{patient_id}/documents/{id}/file` проверяют роль и владельца карты. Пациент видит только свои отчёты; врач может сформировать отчёт выбранного пациента.

Внешний LLM для генерации PDF не используется. Документ содержит пометку, что он автоматически сформирован прототипом, не заменяет подписанное медицинское заключение и требует проверки врачом.

Это защита уровня локального прототипа, а не полноценная медицинская система доступа. Для продуктивной версии нужны настоящая аутентификация, авторизация по владельцу документа, журнал доступа, шифрование хранилища и политика срока хранения.
