# Контекстный помощник врача

Помощник работает внутри карточки выбранного пациента и отвечает на вопросы о динамике, рисках и пробелах в данных.

## Контекст

Перед запросом сервер собирает разрешённую обезличенную выборку:

- возраст;
- клинический профиль;
- результаты шкал;
- самоотчёты;
- приверженность и нежелательные реакции;
- сигналы маршрутизации;
- решения по терапии;
- задачи наблюдения.

ФИО, контакты, переписка и экстренный контакт не передаются. ФИО, телефон, email и длинные идентификаторы удаляются также из текста вопроса и свободных полей карты.

## Ответ

Ответ разделён на три части:

1. факты и выводы по данным случая;
2. сведения врачебной базы с цифровыми ссылками;
3. вопросы и неопределённости для проверки врачом.

Помощник не сохраняет ответ в карту, не устанавливает диагноз и не изменяет терапию или маршрутизацию.

Endpoint: `POST /api/patients/{patient_id}/case-assistant/answer`. Доступен только роли врача.

## Проверка

```bash
.venv/bin/python -m unittest tests.test_case_assistant -v
```

## Краткий формат

Ответ ограничен 180 словами и не должен перечислять всю историю измерений. Сервер отдельно вычисляет временной охват данных. Повторные PHQ-9/GAD-7 в течение одного дня помечаются как недостаточный интервал для надёжного вывода о динамике. Помощник не должен описывать такие колебания как улучшение, ухудшение или эффект лечения.
