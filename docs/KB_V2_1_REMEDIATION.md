# KB v2.1: результаты нормализации

Дата сборки: 2026-10-26.

## Что исправлено автоматически

- Удалены 238 чанков-заглушек с текстом `PDF`.
- Все активные чанки получили область доступа `doctor`.
- В активный корпус вошли только записи с отметкой проверки источника.
- Строки препаратов без подтверждённой карточки инструкции исключены из retrieval.
- Неполностью формализованные safety rules исключены из исполняемого набора.
- Для 16 формализованных safety rules созданы и выполнены позитивные и негативные тесты.
- Для каждого исключения сохранена причина в `quarantine/exclusions.jsonl`.
- В активном врачебном корпусе сформировано 88 содержательных чанков.

## Что находится в карантине

Всего 166 записей:

- 143 записи без отметки клинической проверки;
- 7 записей без подтверждённой инструкции;
- 11 записей одновременно не проверены и не имеют инструкции;
- 5 правил требуют ручной формализации сложного триггера.

## Оставшиеся ограничения

Они не могут быть сняты автоматически без подмены медицинской проверки:

1. 20 eval-кейсов должны быть подтверждены клиническим редактором.
2. Для пациентского корпуса нужны отдельные тексты простым языком и статус `patient_approved`.
3. Для двух клинических рекомендаций в поставке отсутствуют исходные PDF.
4. Для источников не зафиксированы условия повторного использования.
5. Записи в карантине требуют проверки врача или официальной инструкции.

KB v2.1 разрешена для разработки экспериментального поиска врача. Она не разрешена для самостоятельной выдачи пациенту и автоматического изменения лечения.
